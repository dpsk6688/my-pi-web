🚀 快速开始

一键启动（推荐）：

Windows: 双击 start.bat
Mac/Linux: chmod +x start.sh && ./start.sh
→ 自动拉模型、写 .env.local、启动 dev
→ 打开 http://localhost:30141

手动启动：

ollama serve
ollama pull qwen2.5-coder:7b
cd my-pi-web-mvp
npm install --registry=https://registry.npmmirror.com
echo "OLLAMA_MODEL=qwen2.5-coder:7b" > .env.local
echo "OLLAMA_HOST=http://127.0.0.1:11434" >> .env.local
npm run dev

❓ 常见问题

Ollama 连接失败

next 不是内部命令

页面白屏

🏗️ 架构

浏览器 ChatWindow
  └─ useAgentSession hook (SSE)
      └─ GET /api/agent/[id]/events?message=
          └─ lib/local-agent.ts
              ├─ Ollama /api/chat 流式
              ├─ 解析 tool_calls
              ├─ callTool → fs.writeFile 真实写盘
              └─ 递归让模型总结
          └─ SSE → 前端打字机 + 🔧 可视化

关键文件：app/api/agent/[id]/events/route.ts / lib/local-agent.ts / hooks/useAgentSession.ts
